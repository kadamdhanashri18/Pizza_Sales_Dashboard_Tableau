# Pizza_Sales_Dashboard_Tableau
🍕 Tableau + SQL Pizza Sales Analysis Dashboard | Data Analytics Project

Excited to share my Pizza Sales Analysis Project, where I combined SQL and Tableau to transform raw sales data into meaningful business insights.

📊 Key Analysis Covered:
• Total Revenue & Average Order Value
• Total Orders & Total Pizzas Sold
• Hourly & Weekly Sales Trends
• Sales by Pizza Category & Size
• Best/Worst Selling Pizzas
• Orders & Pizza Quantity by Category
• Peak Hours and Weekly Sales Patterns

🛠️ Tools & Technologies:
🔹 SQL – Data querying, aggregation & analysis
🔹 Tableau – Data visualization & interactive dashboard
🔹 Data Analysis – Identifying trends, patterns & business insights

💡 Key Learning:
This project helped me understand how SQL can be used to extract and analyze data, while Tableau can turn those findings into interactive visualizations that support business decision-making.

I’m continuously building my skills in SQL, Tableau, Power BI, Excel, Python & Data Analytics and looking forward to applying them to real-world problems.
